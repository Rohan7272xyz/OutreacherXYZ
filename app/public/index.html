Welcome 👋

OutreacherXYZ finds content creators on Instagram and TikTok, collects their public contact emails, and drops every lead into a Google Sheet you own.

  • Runs on your computer. Nothing is uploaded anywhere except your own Google Sheet.
  • You stay in control. A browser window opens, you log in to your account, and the tool does the tedious part.
  • One-time setup. The next three steps take about 10 minutes, once.

Install the engine

The scraper needs a couple of components. Click the button and let it run — it can take a few minutes.

  • Node.js
  • Scraper libraries
  • Browser engine (Chromium)

    

  


  
  

    
Give it Google access

    
The tool writes leads into a Google Sheet using its own robot account
    (a “service account”). You create one in Google Cloud and hand its key file to the tool.
    Fiddly, but one-time — follow along:

    
    
      
  1. Open console.cloud.google.com/projectcreate and create a project (any name, e.g. outreacher).
    2. 
      
  2. Enable the Sheets API for it: click here → Enable.
    3. 
      
  3. Go to Service accounts → Create service account (any name) → Done. No roles needed.
    4. 
      
  4. Click the account you just made → Keys tab → Add key → Create new key → JSON. A .json file downloads.
    5. 
      
  5. Drop that file below.
    6.
